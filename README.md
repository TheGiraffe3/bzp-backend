## BZP • BZFlag Plugins • Backend

This repository hosts the backend Javascript files for [BZP](https://bzp.sandybees.com).  It uses [PocketBase](https://ganigeorgiev.com/pocketbase/pocketbase) as a database, so the backend is largely a way to send PocketBase requests and files while also keeping it behind a firewall.  If you want to discuss BZP in general, the forum topic may be best suited.

See also the [BZP frontend](https://github.com/TheGiraffe3/bzp-frontend).

If you would like to create another service that talks to the BZP backend, read the [API docs](./API.md).

Contributions welcome!
